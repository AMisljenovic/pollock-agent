This command is for **dogfooding the philosophy**, not for routine development. It is opt-in. Use it when you want to experience the constraints PollockAgent imposes on itself.

Read CLAUDE.md if you need context. Then:

- Pick ONE file in the canvas.
- Make ONE small change. 100–120 lines maximum.
- Do not write planning comments. No `// TODO`, no `// first I'll...`, no roadmap-in-comments.
- React to what is already there. Don't sketch a future plan.
- Rewriting is allowed only as a response to friction already on the page — not pre-emptively.

State in one sentence what existing code suggested the move. Then stop. Don't chain into a second drip.
